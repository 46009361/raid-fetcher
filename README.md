# All HCB Card Numbers

A simple text file containing every [HCB](https://hcb.hackclub.com/) card number possible, shown in [`output.txt`](output.txt), generated using Python.
At the very least, all my cards start with the same first eight digits. I'm pretty sure at least one of your card numbers is in there! I use spaces as
delimeters.

Any other Celtic Bank card that starts with `4859 5385` is also included here. This information cannot generally be used to complete a transaction alone.

This project helped me understand loops in Python.

The file is exactly 200,000,000 bytes large and can be verifiably regenerated by pasting the following script into your favourite terminal and running:

```zsh
git clone https://github.com/46009361/All-HCB-Card-Numbers.git
cd All-HCB-Card-Numbers
python3 main.py
```

---

> [!TIP]
> - When hovering the code block above, you should be able to copy it in one click.
> - After opening your terminal, both right-click and `Ctrl`+`V` or `Command`+`V` can make pasting really easy.
>    - You don't need to install Python 3 manually. Most Linux terminals come pre-installed with it.
>    - Check if `python3 -V` returns 3.6 or newer to avoid errors; that's when underscores started being supported in numbers.
